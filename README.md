# Azərbaycanda İnflyasiya, Əməkhaqqı və Kadr Axını Analizi (Power BI)

Bu layihə, Azərbaycanda 2010-2025 tarix aralığında müxtəlif iqtisadi sektorlar üzrə inflyasiya təsirli əməkhaqqı dinamikasını, işçi demoqrafiyasını və kadr axınını  vizuallaşdıran interaktiv Power BI dashboard-dur.

## 💡 Əsas Xüsusiyyətlər və Analizlər
* **Makro Göstəricilər:** Orta aylıq nominal əməkhaqqı, Muzdla işləyənlərin sayı , İşə qəbul və İşdən çıxma dinamikası.
* **Sektor Analizi:** Müxtəlif illər və sahələr (Mədənçıxarma, Maliyyə, İnformasiya və Rabitə və s.) üzrə əməkhaqqı müqayisəsi.
* **Kadr Axını (Turnover Rate):** İqtisadi sektorlarda kadr axını və maaş balansı (Bubble chart vasitəsilə)
* **İşdən Çıxma Səbəbləri:** İşçilərin işdənçıxma səbəblərinin nisbəti.

## 🛠️ İstifadə Olunmuş Alətlər
* **Power BI Desktop** — Data modelləşdirilməsi və vizuallaşdırma.
* **DAX (Data Analysis Expressions)** — Metriklərin və kadr axını faizlərinin hesablanması üçün.
* **Power Query** — Məlumatların təmizlənməsi (ETL).
